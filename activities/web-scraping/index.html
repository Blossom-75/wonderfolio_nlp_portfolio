ACTIVITY 03

Web Scraping

Collecting online text for language analysis. The activity sets up a Python workflow for downloading web pages and collecting article text from Meduza. It uses the author Ivan Golunov as the analysis focus and imports tools for text processing, readability, vectorisation, dimensionality reduction and similarity analysis.

Python · Requests · BeautifulSoup · TF-IDF

Objectives

  • Install and import the libraries used in the notebook.
  • Download a source page using requests.
  • Parse HTML with BeautifulSoup and collect article links.
  • Extract article metadata and body text.
  • Prepare text for statistical and NLP analysis.
  • Explore TF-IDF, PCA, scaling and cosine similarity in the analysis workflow.

Concepts & Implementation

01

Prepare the environment

Install and import requests, BeautifulSoup, pandas, NumPy, NLTK, textstat and scikit-learn tools.

02

Configure the source

Set the author focus to Ivan Golunov and specify the Meduza source page used by the notebook.

03

Download the page

Use requests.get() with a user-agent header and timeout handling.

04

Collect links

Parse anchor elements and keep unique Meduza links while excluding the source page itself.

05

Extract article content

The notebook defines a scraping workflow to retrieve page text and article metadata.

06

Prepare for analysis

The notebook imports Counter, TfidfVectorizer, PCA, StandardScaler and cosine_similarity for downstream analysis.

Learning Outcomes

  • Understood the role of HTTP requests in collecting web content.
  • Explored HTML parsing with BeautifulSoup.
  • Saw how article links and page content can be collected programmatically.
  • Identified NLP and machine-learning tools used to prepare and compare scraped text.
