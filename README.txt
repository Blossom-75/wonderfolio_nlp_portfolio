# Little NLP Lab — Activity Vending Machine

## Run locally
1. Extract this folder.
2. Open the `little-nlp-lab` folder in VS Code.
3. Install/use the Live Server extension if needed.
4. Right-click the root `index.html` and choose **Open with Live Server**.
5. Select a product, press **DISPENSE**, then click the dispensed item.

## Folder structure
- `index.html` — main vending machine page
- `css/style.css` — main vending machine styling
- `js/script.js` — product selection, keypad, dispensing and navigation
- `activities/<activity-slug>/index.html` — individual activity page
- `activities/<activity-slug>/style.css` — individual activity styling
- `assets/` and `files/` — images, notebooks and text resources

The activity page folder names and JavaScript paths are normalised to lowercase hyphenated names. Keep those names unchanged unless you also update `js/script.js`.

The private-looking trailing string in the original Translation text file was intentionally excluded from the public website copy.
